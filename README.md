# 🌍 safari Adventures - Travel Website

A modern, responsive tours and travels website with beautiful animations and interactive elements.

![Travel Website](https://images.unsplash.com/photo-1488646953014-85cb44e25828?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80)

## ✨ Features

- **🎨 Modern Design** - Clean layout with attractive color scheme
- **📱 Fully Responsive** - Works perfectly on all devices
- **⚡ Interactive Elements** - Hover effects, animations, and smooth transitions
- **🧭 User-Friendly Navigation** - Smooth scrolling and mobile hamburger menu
- **💫 CSS Animations** - Floating cards and scroll-triggered animations
- **📞 Contact Form** - Functional contact form with validation
- **🎯 Tab System** - Organized tour categories
